`vn-tile-map-editor` is a tile map editor built for the VN-Suit framework. It allows for creating and editing tile maps with multiple layers and tilesets.

Part of the link:../readme.asciidoc[VN-Suit] framework.

== Structure

The project is split into two crates:

* **vn-tile-map-editor-logic**: Contains the core editor state, UI definitions using `vn-ui`, and map manipulation logic. It should be platform-agnostic and can be compiled to WASM.
* **vn-tile-map-editor-native**: The native runner for the editor, providing file system access and OS-level window management via `winit` and `wgpu`.

== Feature Flags

The following feature flags are available:

* `debug_outlines`: Enables visualization of UI element boundaries. Useful for debugging layout issues.
* `example_map`: When enabled, the editor will attempt to load a default example map upon startup.

== How to Start

To run the editor natively, navigate to the `rust/vn-tile-map-editor` directory and use `cargo`:

[source,bash]
----
# Run with default features
cargo run --release -p vn-tile-map-editor-native

# Run with example map loaded
cargo run --release -p vn-tile-map-editor-native --features example_map

# Run with debug outlines enabled
cargo run --release -p vn-tile-map-editor-native --features debug_outlines
----

== Usage

* **Tile Selection**: Left-click / drag to select tiles from the tileset panel on the right.
* **Drawing**: Left-click / drag on the map to place the selected tile.
* **Layers**: Manage layers using the layers panel. You can add, remove, rename, and change the order of layers.
* **Saving/Loading**: Use the UI buttons to save your map to a folder or load an existing one.
* **Brushes**: There are 3 types of brushes.
    - None: Does nothing
    - Eraser: Clears / Erases tiles
    - Tileset: Will draw the selected tileset area. Mouse position corresponds to the top left corner of the selected tiles
